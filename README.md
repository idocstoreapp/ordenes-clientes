# Sistema de Gestión de Órdenes y Reparaciones

Sistema completo de gestión para talleres de reparación de dispositivos Apple, con dos módulos principales:

## 📦 Estructura del Proyecto

- **`sistema-gestion-ordenes/`** - Sistema principal de gestión de órdenes de trabajo
- **`sistema-reparaciones/`** - Sistema de gestión de reparaciones y comisiones

## 🚀 Inicio Rápido

### Requisitos
- Node.js 18+
- Cuenta de Supabase
- npm o yarn

### Instalación

1. Clonar el repositorio:
```bash
git clone <url-del-repositorio>
cd odenes-clientes
```

2. Instalar dependencias de cada sistema:
```bash
cd sistema-gestion-ordenes
npm install

cd ../sistema-reparaciones
npm install
```

3. Configurar variables de entorno (ver documentación en cada sistema)

## 📚 Documentación

Cada sistema tiene su propia documentación completa:

- **Sistema de Gestión de Órdenes**: Ver `sistema-gestion-ordenes/README.md`
- **Sistema de Reparaciones**: Ver `sistema-reparaciones/README.md`

## 🔒 Seguridad

⚠️ **IMPORTANTE**: Nunca subir archivos `.env` o `.env.local` al repositorio. Estos contienen credenciales sensibles.
